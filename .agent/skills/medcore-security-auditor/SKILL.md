# Medcore Security Auditor
Focado em garantir a segurança do sistema SaaS e prevenir vazamento de dados de pacientes (LGPD/HIPAA).
- Auditar RLS do Supabase.
- Auditar injeções de SQL ou chamadas inseguras ao banco.
- Controlar gestão de Tokens, senhas e fluxos de autenticação (Mercado Pago, Supabase Auth).
