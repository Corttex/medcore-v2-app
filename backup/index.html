ℹ️ Documentação técnica da stack e arquitetura do sistema CONTE CORE.
Stack Tecnológica
Frontend
React 18 + TypeScript
Vite, TailwindCSS, React Query, Zustand.
Backend
Node.js + NestJS
Modular, TypeScript nativo, WebSockets.
Banco de Dados
PostgreSQL + Redis
Dados relacionais + cache (Bull). Prisma ORM.
Autenticação
JWT + PIN (TOTP)
Access Token 15min + Refresh 7d. Rate limiting.
Storage
AWS S3 / MinIO
Upload com URLs pré-assinadas. AES-256.
IA
Claude AI (Anthropic)
API v1/messages. Modelo: claude-sonnet-4-20250514.
Segurança & Conformidade
Autenticação por PIN
PIN individual por usuário, 4 dígitos. Bloqueio após 5 tentativas. JWT de curta duração.
Criptografia AES-256
Dados em repouso e em trânsito (TLS 1.3). Campos sensíveis criptografados no banco.
RBAC por Perfil
Administrador, Secretário, Diretor. Permissões por módulo. ACL por documento.
LGPD Compliant
Consentimento registrado. Anonimização. Direito ao esquecimento. RIPD disponível.
